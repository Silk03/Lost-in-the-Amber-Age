# Lost in the Amber Age 🦖🎮

**Lost in the Amber Age** is a completed **educational dinosaur game** developed using **Unity** and **C#**.  
The game is set in a prehistoric world preserved in amber, where players explore ancient environments, learn about dinosaurs, and uncover facts from a forgotten era.

## ✅ Project Status
**Completed Project**

## 🛠️ Tech Stack
- Unity Game Engine
- C# Programming Language

## 🎯 Game Features
- Dinosaur-themed educational gameplay
- Exploration of prehistoric environments
- Informative content about dinosaurs
- Player movement and interaction
- Core game mechanics implemented in C#

## 📚 Educational Focus
- Learn basic facts about dinosaurs
- Understand prehistoric environments
- Combine gameplay with learning elements
- Interactive and engaging educational experience

## 🎮 Gameplay Objective
- Explore the Amber Age world
- Discover dinosaurs and educational content
- Progress through the game’s environment


## 📌 Notes
- This game is designed for educational purposes.
- Suitable for students and players interested in dinosaurs and prehistory.
